# World X Heroes

World X Heroes is a social hero platform built around one idea: **the human is the character**. Real-world skills, creativity, accomplishments, kindness, learning, and meaningful contributions form a Hero's evolving identity.

## Alpha

The current playable slice includes the celestial opening, Hero creation, masked or visible identity, five starting attributes, a local Hero profile and card, and proof-backed achievement submissions.

Submitted evidence is explicitly marked unverified. XP is not awarded until an achievement has been reviewed and verified. Merit scoring, AI review, and server-side accounts are not implemented in this local alpha. Hero data and small image evidence are stored in the browser on the current device.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and create a production build.
